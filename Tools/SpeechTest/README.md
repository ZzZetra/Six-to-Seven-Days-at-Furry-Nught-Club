# Тест распознавания слов с микрофона

Маленькое отдельное приложение, чтобы подобрать, как игра будет понимать слова игрока.
Движок — **[Vosk](https://alphacephei.com/vosk/)**: офлайн, без интернета и ключей, есть русский, умеет
слушать **только заданный список слов**, что удобно для игровых команд.

## Запуск

- **`run.bat`** — окно с микрофоном.
- `setup.bat` — установка с нуля на другом компьютере: окружение Python 3.14, пакеты `vosk` и
  `sounddevice`, русская и английская модели. Здесь уже всё установлено.
- `run.bat --wav файл.wav [--lang en|ru] --variant words|phrase|free [--window 4] [--distinct]` — распознать запись
  (16 кГц, моно, 16 бит), в консоль — что услышано и какие тройки собраны.

## Тройки слов (мониторный вирус)

Главное — ловить **комбинацию из трёх слов** verity / lovety / moggaty: в игре это будет мониторный
вирус, на мониторе код из трёх слов, его надо произнести.

### Язык: English (по умолчанию) или Русский

Переключатель «Язык» вверху окна. У каждого языка своя модель и свои синонимы.
**По умолчанию английский:** на тестах он точнее, к тому же английская модель в варианте «По словам»
поймала и тройки, произнесённые русским голосом, то есть к акценту она терпима.

| Говоришь (голос Zira) | Английская модель слышит | Команда |
|---|---|---|
| verity | **verity** (слово есть в словаре) | **VERITY** |
| lovety | «love eddie», «love eddy»; luvvity → «levity», «lovie» | **LOVETY** |
| moggaty | «margaret he», «marguerite», в режиме списка «mog eddy», «mog he»; mogaty → «mccarty» | **MOGGATY** |

Проверка, английская модель:

| Запись | По словам | Фразой | Свободная + поиск |
|---|---|---|---|
| 5 английских троек (на одном дыхании, с паузами, с повторами) | **5 из 5** | 5 из 5 | 3 из 5 |
| 2 записи русских троек (голос Irina) | 2 из 2 | 2 из 2 | 0 из 2 |
| посторонняя английская фраза | 0 ложных | 0 ложных | 0 ложных |
| посторонняя русская речь (2 записи) | **0 ложных** | **1 ложная** | 0 ложных |

Вывод: для английского лучший вариант — **«По словам»**. «Фразой» на русской речи один раз выдумал тройку:
он слишком хочет найти тройку и подгоняет под неё что угодно.

### Синонимы (русская модель)

В словаре русской модели этих выдуманных слов нет, поэтому у каждой команды — **синонимы**: то, что
модель на самом деле слышит, когда их произносишь по-русски:

| Говоришь | Модель слышит | Команда |
|---|---|---|
| «верити», «вэрити» | «верите», «верить» | **VERITY** |
| «лавити», «ловити» | «ловите», «ловить» | **LOVETY** |
| «моггати», «могати» | «мага те», «мага ти», «магазин» | **MOGGATY** |

Синоним «мог а ты» убран: срабатывал на обычной фразе с уверенностью 1.00. Английское произношение
русская модель не понимает.

### Три варианта распознавания

| Вариант | Как | Когда хорош |
|---|---|---|
| **По словам** | модель ищет только синонимы и служебные слова; тройка собирается из слов, сказанных в пределах **окна** (4 с) | можно с паузами |
| **Фразой** | модель заранее знает все тройки целиком (плюс одиночные слова и служебные) | на одном дыхании, точнее при шуме |
| **Свободная речь + поиск** | распознаёт всё подряд, тройку ищет в тексте | ничего не ограничивает; ловит, только если синонимы покрывают то, что слышит модель |

### Задание

- **Код вируса** — случайный код из трёх слов. Сказал верно — «ВИРУС УДАЛЁН за N с», неверно — «НЕВЕРНО».
  По умолчанию слова могут повторяться и идти подряд (`LOVETY · LOVETY · VERITY`) — все 27 кодов.
  Галочка «без повторов» — только 6 кодов из трёх разных слов.
- **Любая тройка** — показывает любую услышанную тройку.
- Строка «Слышу: VERITY · _ · _» — что уже собрано. Статистика слева: сколько троек, верных, неверных,
  точность, среднее время до успеха.

### Проверка на синтезированной речи (голос Irina)

| Запись | По словам | Фразой | Свободная + поиск |
|---|---|---|---|
| тройка на одном дыхании | ✔ | ✔ | ✔ |
| тройка с паузами по 1 с | ✔ | ✔ | ✔ |
| паузы по 5 с (больше окна) | не засчитана — верно | не засчитана | не засчитана |
| две тройки подряд | ✔ ✔ | ✔ ✔ | ✔ ✔ |
| тройка с повтором (lovety lovety verity) | ✔ | ✔ | ✔ |
| ещё 6 троек с повторами подряд (moggaty moggaty verity, verity ×3, moggaty ×3…), быстро и с паузами | 6 из 6 | 6 из 6 | 4 из 6: «моггати моггати» на одном дыхании слышит как «мага тим агате» |
| посторонняя речь (2 записи) | 0 ложных | 0 ложных | 0 ложных |

Свободный вариант заработал только после того, как в синонимы добавили «верить», «ловить», «мага ти»,
«магазин» — то, что он слышит на этих словах. На синтезированной речи все три варианта одинаковы,
разницу покажет живой голос и шум. **Для вируса надёжнее «По словам» и «Фразой»:** свободный вариант
путается на одинаковых словах подряд.

**Как подгонять под свой голос:** вариант «Свободная речь + поиск», скажи слово несколько раз, посмотри в
журнале, что слышит модель, допиши это в синонимы через запятую, «Применить».

## Что в окне

| Элемент | Зачем |
|---|---|
| Микрофон | выбор устройства; полоска под ним — громкость (красная — перегруз) |
| **Только слова из списка** | Vosk ищет только фразы из списка слева. Быстро и точно для команд |
| **Свободная речь** | распознаёт всё подряд, как диктовка |
| Мин. уверенность | слова с уверенностью ниже порога серые и не засчитываются |
| Вариант, окно | как ловить тройку (см. выше) и за сколько секунд её надо сказать |
| Задание | код вируса или любая тройка; «Новый код» |
| Команды | `имя: синоним, синоним` по строкам; «Применить» перезапускает распознавание |
| Служебные слова | идут в грамматику, чтобы посторонняя речь не превращалась в команды; не считаются |
| Код, «Слышу», результат | код вируса, собранная часть тройки, «ВИРУС УДАЛЁН» / «НЕВЕРНО» |
| Сколько раз распознано | счётчик по каждой фразе — видно, что срабатывает часто, а что нет |
| Журнал | время, `[уверенность]`, принятые слова (зелёные — совпали со списком), отброшенные, сколько мс считалось |
| Модель… | выбрать другую папку модели |

## Что уже выяснили (проверка на синтезированной речи)

Записи — голос Microsoft Irina, модель `vosk-model-small-ru-0.22`:

| Проверка | Результат |
|---|---|
| Команды («закрой дверь», «генератор», «покорми», «звук», «открой дверь», «стоп»), режим «список» | все 6 верно, уверенность 1.00, 0.2 с на всю запись |
| Те же команды, свободный режим | все верно, но медленнее (0.9 с) |
| Обычная фраза «Нова идёт по коридору к дэнс полу, а Дали уже у генератора», свободный режим | почти верно, «Дали» → «**отдали**» |
| Та же фраза в режиме «список» | **ложные срабатывания:** «покорми доли пол доли генератор», уверенность 0.94 |
| Режим «список» + служебные слова (а, и, у, к, по, уже, это, ну, да, нет, вот, там) | ложное «покорми» ушло, команды по-прежнему 100% |

Выводы для подгонки:
1. **Режим «список» подгоняет любую речь под слова из списка**, и порог уверенности это не ловит.
   Помогает добавить в список частые служебные слова: они «впитывают» лишнюю речь.
2. **Важные команды лучше из двух слов** («закрой дверь», а не «дверь»): двухсловная фраза случайно
   совпадает гораздо реже.
3. **Слова «стрей» нет в словаре модели**, Vosk его пропускает. Для имён можно взять похожее известное
   слово, большую модель или свободный режим.
4. **«Дали» и «Доли» на слух почти одинаковые**, распознавание их путает. Если имена будут голосовыми
   командами, одно из них стоит переименовать.

## Как это потом попадёт в игру

У Vosk есть C#-привязка (NuGet-пакет `Vosk` с нативной `libvosk.dll`) и готовая интеграция с Unity
(`vosk-unity-asr`). Модель кладётся в `StreamingAssets`, микрофон — через `Microphone` Unity, режим
«список» — тот же JSON со словами. Здесь мы подбираем слова, порог и режим, чтобы перенести в игру уже
проверенное.
