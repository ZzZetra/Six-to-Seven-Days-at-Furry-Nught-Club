# SSDFNC — Six to Seven Days at the Furry Night Club

FNAF-подобная игра на выживание про фурри, Unity, 3D, модели в стиле Roblox. Игрок дежурит днём
на ресепшене пустого ночного фурри-клуба и держит оборону от пяти фурри. Ресурсов четыре:
бензин для генератора, дэнс пол, кнопка звука и дверь. С Новой отдельно идёт мог-батл.
Подробно — в [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md).

> **Статус: ранний прототип.** Готовы главное меню с настройкой ночи, смена, офис (генератор,
> дверь, дэнс пол, кнопка звука), пятеро фурри с ИИ как во FNAF, монитор на 8 камер с кормлением
> Дира, атака Новы по фазам с четырьмя видами скилл-чеков под музыку (раскладки для них делает отдельная
> программа — редактор раскладок)
> и звонки клиентов с расписанием на ночь (за верные ответы — деньги). Модели из Blender: генератор
> и Нова, остальные фурри пока капсулы.

## Как запустить

1. Unity Hub → **Add** → папка `C:\Users\user\SSDFNC`. Версия редактора — **6000.6.0f1**.
2. Нажать **Play**. Игра всегда стартует с главного меню, какая бы сцена ни была открыта. В
   меню нажать **«Начать ночь»**. Чтобы Play запускал открытую сцену (например сразу офис),
   сними галочку **SSDFNC → Play From Main Menu**.
3. Когда сборщик офиса обновляется (например, добавился генератор), Unity после загрузки скриптов
   сам спросит: **«Пересобрать сцену офиса сейчас?»**. Жми «Пересобрать».
   Сцену в любой момент можно собрать заново и вручную, из меню **SSDFNC** в верхней строке
   Unity (рядом с Window и Help):
   - **Build Main Menu** — сцена меню и список сцен в Build Settings;
   - **Build Test Platform** — офис. Всё, что лежит внутри `TestPlatform` и `Shift`, при этом
     удаляется;
   - **Chart Editor → Open in Play Mode** — редактор раскладок прямо в Unity;
   - **Chart Editor → Build App (.exe)** — собрать редактор раскладок отдельной программой.
4. **Редактор раскладок скилл-чеков** — отдельная программа `Builds/ChartEditor/SSDFNC Chart Editor.exe`
   (папка `Builds` в git не хранится: на другом компьютере собрать заново командой выше).

## Репозиторий

Проект в git с 2026-10-23, основная ветка `main`.

- **Не хранится в git** (Unity создаёт сам): `Library`, `Temp`, `Logs`, `UserSettings`, файлы `.sln` и
  `.csproj`. Первое открытие после клонирования идёт несколько минут — Unity заново импортирует ассеты.
- **Музыка, модели и большие текстуры** (`.wav`, `.mp3`, `.ogg`, `.fbx`, `.blend`, `.psd` …) хранятся
  через **Git LFS** (`.gitattributes`). В Git for Windows он уже есть; на другом компьютере — `git lfs install`.
- **Тест распознавания речи:** `Tools/SpeechTest/.venv` и модели Vosk не хранятся — их ставит
  `Tools/SpeechTest/setup.bat`.
- В каждом коммите обновлять `README.md` и `CHANGELOG.md`.

**Чтобы быстро проверить конец смены,** нажми в игре **F9**: смена сразу закончится, и игра
вернётся в меню. Каждый переход пишется в Console: `[SSDFNC] Начать ночь`,
`[SSDFNC] Смена окончена, возврат в меню`, `[SSDFNC] Выйти`.

**Все числа игры** (длина смены, генератор, дверь, фурри) — в одном файле
[Balance.cs](Assets/Scripts/Core/Balance.cs). **Сложность по умолчанию** (уровни ИИ фурри, Easy / Normal / Hard /
Custom) — в [Difficulty.cs](Assets/Scripts/Core/Difficulty.cs); перед ночью её можно поменять в меню, вкладка «Настройка ночи». Смена — 10 минут
(`ShiftDuration` = 600 с). Чтобы быстро проверить конец смены, в игре есть F9. После правки переключись в Unity, он перекомпилирует скрипт.

**Тесты:** Window → General → Test Runner → EditMode → Run All (71 тест: фурри, баланс, мог-батл, звонки).
**Баланс:** меню SSDFNC → Balance Report пересчитывает [docs/BALANCE_REPORT.md](docs/BALANCE_REPORT.md).

## Управление

| Клавиша | Действие |
|---|---|
| **A** / **←** | повернуться на шаг влево |
| **D** / **→** | повернуться на шаг вправо. У генератора — вернуться в офис |
| **W** / **↑** | пройти в комнату, на которую смотришь. Пока это только генератор слева |
| **S** / **↓** | вернуться в офис |
| **ЛКМ** по кнопкам 2–8, Г | выбрать камеру: на экране кто в комнате |
| **ЛКМ держать** «ПОКОРМИТЬ» на камере 7 | накормить Дира (1.5 с) |
| **ЛКМ** в меню | вкладка «Главная»: «Начать ночь» / «Выйти»; вкладка **«Настройка ночи»**: уровни фурри − / +, Easy / Normal / Hard, «Только Нова», «По умолчанию»; вкладка **«Скилл-чеки»**: проверить раскладку |
| **Пробел** в мог-батле | кружок и полоска: попасть, пока стрелка / метка в зелёной зоне |
| **ЛКМ** по кнопке в мог-батле | кнопка: клик, когда кольцо сомкнётся с ней |
| **Взмах мышью** в мог-батле | стрелка: провести мышью в её сторону, пока кольцо не сомкнулось |
| **Esc** | прервать проверку скилл-чеков (в меню и в редакторе раскладок) |
| **ПРОБЕЛ / B / Delete / Ctrl+S** в редакторе раскладок | играть-пауза / чек под бит / удалить чек / сохранить |
| **ЛКМ** по ручке генератора | рывок стартера: заглохший генератор заводится (только вблизи) |
| **ЛКМ держать** на «ЗАЛИТЬ» | переливать бензин из канистр в бак (только вблизи) |
| **ЛКМ** по телефону, когда звенит | взять трубку |
| **ЛКМ** где угодно | показать варианты ответа клиенту |
| **1** / **2** / **3** или **ЛКМ** по варианту | ответить клиенту (окно звонка видно, только когда смотришь вперёд) |
| **F9** | сразу закончить смену (только в редакторе и dev-сборке) |
| **F1** | панель сложности во время ночи: уровни фурри, пресеты, «Только Нова», «Нова → батл», «Вызвать звонок» |
| **Пробел** — смотришь вперёд | дэнс пол горит, пока держишь пробел (отвернулся — гаснет) |
| **Пробел** — смотришь вправо | рычаг двери: закрыть / открыть |
| **ЛКМ держать** розовую кнопку на столе | дэнс пол впереди горит, пока держишь |
| **ЛКМ** по красной кнопке на столе | один звуковой сигнал |
| **ЛКМ** по рычагу справа от правого проёма | закрыть / открыть дверь |
| **F6 / F7 / F8** | заглушить генератор / −20 HP / слить 10 бензина (отладка, пока нет фурри) |

В офисе камера встаёт в три положения: влево (−90°), вперёд (0°), вправо (+90°). Следующая
команда срабатывает, когда камера почти доехала: поворот около 0.65 с, подход к генератору около
1.2 с.

## Что уже есть

- **Главное меню** (`MainMenu`) — вкладки «Главная» («Начать ночь», «Выйти»), «Настройка ночи»:
  уровень каждого фурри до начала ночи (`NightSettingsTab`, запоминается между запусками), и
  «Скилл-чеки» (`MogTestTab`): выбрать раскладку и пройти её в окне мог-батла — сразу с первого чека.
- **Смена** (`ShiftTimer`) — по дизайну идёт 10 минут (сейчас полторы минуты), в
  правом верхнем углу часы с оставшимся временем.
  Время вышло — возврат в меню.
- **Поворот камеры** (`CameraLook`) — три направления, плавный доворот без рывка в конце, и
  подход к генератору через проём.
- **Стены офиса** слева и справа, в каждой дверной проём 1.2 × 2.2 м. Слева за проёмом
  генератор, справа коридор, где потом будет дверь.
- **Генератор** (`Generator`, `GeneratorModel`, `GeneratorHandle`, `GeneratorPanel`) — за проёмом слева,
  в 6.5 м. Модель из Blender с анимациями:
  - рывки стартера — генератор заводится через 2.6 с;
  - работающий трясётся;
  - пока заливаешь бензин, крышка бака открыта.

  Пользоваться им можно только вблизи (ближе 3 м), то есть подойдя: смотришь влево и жмёшь W.
  Работает и жжёт бензин (150 за смену). На табло состояние, полоски HP и бензина, остаток в канистрах
  и кнопка «Залить». Кончился бензин — глохнет, заводится кликом по ручке стартера на боку. HP на нуле —
  сломан до конца смены. Числа — в `Balance.cs`. Как обновить модель — [docs/MODELS.md](docs/MODELS.md).
- **Фурри** (`SSDFNC.Core`, `NightDirector`) — пятеро, ИИ как во FNAF: уровень 0–20, бросок кубика
  каждые ~5 с, рост уровня за смену, фиксированные маршруты. Дир в кормушке, Стрей к двери или дэнс
  полу, Нова на дэнс пол (мог-батл), Дали к генератору, Доли к
  двери или генератору. У двери, на дэнс полу, в проходе Г и у генератора их видно: Нова — модель из
  Blender, остальные пока цветные капсулы.
  Нападение — красный экран и смена заново. Подробно — [docs/FURRY_AI.md](docs/FURRY_AI.md).
- **Атака Новы (мог-батл)** (`MogBattle`) — по фазам: Появление → группы скилл-чеков → Нова уходит
  или Смерть. Фаза пишется в правом верхнем углу под часами. Нова разворачивает игрока к дэнс полу,
  управление отключено, остальные фурри стоят. Четыре вида скилл-чеков:
  - **кружок** — стрелка бежит по кругу, ПРОБЕЛ в зоне (как в DbD);
  - **кнопка** — как в osu!: круг с белой обводкой, кольцо проявляется и сжимается, клик, когда
    сомкнётся с обводкой; после клика вспышка (белая — попал, красная — мимо);
  - **стрелка** — ждёт взмаха: провести мышью в её сторону, пока кольцо не сомкнулось (не туда — не
    считается; не успел — стрелка краснеет, промах);
  - **полоска** — метка едет, может менять скорость и отскакивать от краёв, ПРОБЕЛ в зоне.

  Чеки идут один за другим: следующий виден сразу, как решён предыдущий, и ждёт своего времени.
  Скилл-чеки идут по **раскладкам под музыку** — json-файлам в `Assets/StreamingAssets/MogCharts`.
  Запас мога: с 3, попал — +1 (до 4), промах — −1; на 0 Нова нападает сразу, дожил хотя бы с 1 — выжил.
- **Редактор раскладок** — отдельная программа `Builds/ChartEditor/SSDFNC Chart Editor.exe`
  (`MogChartEditor`, сцена `MogEditor`; в Unity — SSDFNC → Chart Editor → Open in Play Mode). Импорт
  музыки, волна звука, сетка по BPM, чеки ставятся клавишей B в такт. Выбранный чек виден посередине в
  настоящем окне скилл-чеков, и его можно править мышью прямо там: место кнопки, где зона и какой она
  ширины. Справа — точные числа (скорость, зона, время). Проверка раскладки в окне мог-батла, сохранение
  в json папки проекта, его сразу подхватывает игра. Как пользоваться — [docs/MOG_CHARTS.md](docs/MOG_CHARTS.md).
- **Звонки клиентов** (`CallDirector`, `Phone`, `CallDialog`, `ScheduleBoard`) — 4–6 звонков за смену.
  Клиенты спрашивают, что и когда будет ночью, кто свободен, хотят заказать фурри или VIP-комнату.
  Отвечать по табличке «Программа на ночь» справа над столом, она каждую ночь новая. Окно разговора внизу,
  видно, когда смотришь вперёд. За верный ответ 2–10 $, деньги — в меню. Диалоги — json в
  `Assets/StreamingAssets/Calls`, как их писать — [docs/CALLS.md](docs/CALLS.md).
- **Монитор камер** (`CameraMonitor`) — 8 камер: комнаты 2–8 и проход Г, на экране кто в комнате.
  На камере 7 — корм Дира и кнопка «ПОКОРМИТЬ». Без питания от генератора гаснет.
- **Отпугивающие факторы** (`Deterrent`) — три вида срабатывания: **разово** (нажал — сработал),
  **пока держишь**, **вкл/выкл** (нажал — включил, ещё раз — выключил).
  - **Дэнс пол** (`DanceFloor`) — плитки в коридоре впереди, кнопка на столе, работает, пока держишь.
    Нужен генератор.
  - **Звук** (`SoundSignal`) — кнопка на столе, один гудок за нажатие. Работает и без генератора.
  - **Дверь** (`Door`) — в правом проёме, рычаг на стене, вкл/выкл. Закрытой можно держать не
    дольше 20 с, потом откроется сама и заблокируется на 10 с. Табличка над рычагом показывает
    отсчёт. Без генератора дверь открывается, рычаг не работает.
- **Сборщики сцен** (`TestPlatformBuilder`, `MainMenuBuilder`, `MogEditorBuilder`) — собирают офис,
  меню и редактор раскладок одной командой; `MogEditorBuilder` ещё и собирает редактор отдельной программой.

## Тестовая сцена (вид сверху)

```
                               ● зелёный шар
                               │
                          ForwardPath
                               │
        ▣ генератор ··        ║[ центр 8×8 ]║        ▮ синий цилиндр
 LeftPath ═════════ ◇ ══ проём ║     ▲      ║ проём ══ RightPath ═════════
                               ║   игрок    ║
                      стена x = −3.5      стена x = +3.5
   ◇ — где встаёт камера у генератора (x = −4.65), глаза на высоте 1.6 м
```

Монитор стоит перед игроком справа внизу: виден, когда смотришь вперёд, и пропадает из
виду при повороте влево или вправо. Под ним ряд из шести цветных кнопок.

Подробно про координаты и устройство — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
