# SSDFNC — Six to Seven Days at the Furry Night Club

FNAF-подобная игра на выживание про фурри, Unity, 3D, модели в стиле Roblox. Игрок дежурит днём
на ресепшене пустого ночного фурри-клуба и держит оборону от пяти фурри. Ресурсов четыре:
бензин для генератора, дэнс пол, кнопка звука и дверь. С Новой отдельно идёт мог-батл.
Подробно — в [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md).

> **Статус: ранний прототип.** Готовы 7 ночей по 6 минут (открываются по очереди), главное меню со «Своей
> ночью», офис (генератор,
> дверь, дэнс пол, кнопка звука), пятеро фурри с ИИ как во FNAF, монитор на 7 камер с кормлением
> Дира, атака Новы по фазам с четырьмя видами скилл-чеков под музыку (раскладки для них делает отдельная
> программа — редактор раскладок)
> и звонки клиентов с расписанием на ночь (за верные ответы — деньги). Модели из Blender: карта клуба,
> генератор и все фурри.

## Как запустить

1. Unity Hub → **Add** → папка `C:\Users\user\SSDFNC`. Версия редактора — **6000.6.0f1**.
2. Нажать **Play**. Игра всегда стартует с главного меню, какая бы сцена ни была открыта. В
   меню нажать **«Начать ночь»**. Чтобы Play запускал открытую сцену (например сразу офис),
   сними галочку **SSDFNC → Play From Main Menu**.
3. Когда сборщик офиса обновляется (например, добавился генератор), Unity после загрузки скриптов
   сам спросит: **«Пересобрать сцену офиса сейчас?»**. Жми «Пересобрать».
   Сцену в любой момент можно собрать заново и вручную, из меню **SSDFNC** в верхней строке
   Unity (рядом с Window и Help):
   - **Build Main Menu** — сцены Boot (загрузочный экран при запуске) и меню, список сцен в Build Settings;
   - **Build Test Platform** — офис. Всё, что лежит внутри `TestPlatform` и `Shift`, при этом
     удаляется;
   - **Chart Editor → Open in Play Mode** — редактор раскладок прямо в Unity;
   - **Chart Editor → Build App (.exe)** — собрать редактор раскладок отдельной программой.
4. **Редактор раскладок скилл-чеков** — отдельная программа `Builds/ChartEditor/SSDFNC Chart Editor.exe`
   (папка `Builds` в git не хранится: на другом компьютере собрать заново командой выше).

## Репозиторий

Проект в git с 2026-10-23, основная ветка `main`.

- **Не хранится в git** (Unity создаёт сам): `Library`, `Temp`, `Logs`, `UserSettings`, файлы `.sln` и
  `.csproj`. Первое открытие после клонирования идёт несколько минут — Unity заново импортирует ассеты.
- **Музыка, модели и большие текстуры** (`.wav`, `.mp3`, `.ogg`, `.fbx`, `.blend`, `.psd` …) хранятся
  через **Git LFS** (`.gitattributes`). В Git for Windows он уже есть; на другом компьютере — `git lfs install`.
- **Тест распознавания речи:** `Tools/SpeechTest/.venv` и модели Vosk не хранятся — их ставит
  `Tools/SpeechTest/setup.bat`. Обучение своей модели: `Tools/SpeechTrain/.venv`, голоса Piper и примеры
  (`voices/`, `data/`) не хранятся — их ставит `Tools/SpeechTrain/setup.bat`; сами модели (`features/`, `models/`,
  ~3 МБ) — в гите.
- В каждом коммите обновлять `README.md` и `CHANGELOG.md`.

**Чтобы быстро проверить конец смены,** нажми в игре **F9**: смена сразу закончится, и появится
экран «Ночь окончена». Каждый переход пишется в Console: `[SSDFNC] Начать ночь`, `[SSDFNC] Загрузка: …`,
`[SSDFNC] Смена окончена`, `[SSDFNC] Пауза`, `[SSDFNC] Выйти`.

**Все числа игры** (длина смены, генератор, дверь, фурри) — в одном файле
[Balance.cs](Assets/Scripts/Core/Balance.cs). **Сложность по умолчанию** (уровни ИИ фурри, Easy / Normal / Hard /
Custom) — в [Difficulty.cs](Assets/Scripts/Core/Difficulty.cs), для «Своей ночи» её можно поменять в меню. **Ночи 1–7**
(кто участвует, уровни, сбои монитора, сколько звонков) — в [Nights.cs](Assets/Scripts/Core/Nights.cs). Смена — 6 минут
(`ShiftDuration` = 360 с). Чтобы быстро проверить конец смены, в игре есть F9. После правки переключись в Unity, он перекомпилирует скрипт.

**Тесты:** Window → General → Test Runner → EditMode → Run All (75 тестов: фурри, баланс, мог-батл, звонки, сбой монитора).
**Баланс:** меню SSDFNC → Balance Report пересчитывает [docs/BALANCE_REPORT.md](docs/BALANCE_REPORT.md).

## Управление

| Клавиша | Действие |
|---|---|
| **A** / **←** | повернуться на шаг влево |
| **D** / **→** | повернуться на шаг вправо. У генератора — вернуться в офис |
| **W** / **↑** | пройти в комнату, на которую смотришь. Пока это только генератор слева |
| **S** / **↓** | вернуться в офис |
| **ЛКМ** по кнопкам 1–7 | выбрать камеру: кадр камеры или текстом, кто в комнате (камера 1 не работает) |
| **ЛКМ держать** «ПОКОРМИТЬ» на камере 7 | накормить Дира (1.5 с) |
| **ЛКМ** в меню | **«Играть»** → выбрать ночь в списке → «Играть» ещё раз; **«Настройки»** → «Громкость», «Звуки», «Скилл-чеки»; «Выход» |
| **Esc** в меню | на шаг назад (из списка ночей и настроек) |
| **Пробел** в мог-батле | кружок и полоска: попасть, пока стрелка / метка в зелёной зоне |
| **ЛКМ** по кнопке в мог-батле | кнопка: клик, когда кольцо сомкнётся с ней |
| **Взмах мышью** в мог-батле | стрелка: провести мышью в её сторону, пока кольцо не сомкнулось |
| **Esc** в офисе | пауза: «Продолжить», «Начать ночь заново», «Звуки», «В главное меню», «Выйти из игры» |
| **Esc** в меню | прервать проверку скилл-чеков (и в редакторе раскладок) |
| **ПРОБЕЛ / B / Delete / Ctrl+S** в редакторе раскладок | играть-пауза / чек под бит / удалить чек / сохранить |
| **ЛКМ** по ручке генератора | рывок стартера: заглохший генератор заводится (только вблизи) |
| **ЛКМ держать** на «ЗАЛИТЬ» | переливать бензин из канистр в бак (только вблизи) |
| **ЛКМ** по телефону, когда звенит | взять трубку |
| **ЛКМ** где угодно | показать варианты ответа клиенту |
| **1** / **2** / **3** или **ЛКМ** по варианту | ответить клиенту (окно звонка видно, только когда смотришь вперёд) |
| **F9** | сразу закончить смену (только в редакторе и dev-сборке) |
| **F1** | панель сложности во время ночи: уровни фурри, пресеты, «Только Нова», «Нова → батл», «Вызвать звонок», «Сбой монитора» |
| **Пробел** — смотришь вперёд | дэнс пол горит, пока держишь пробел (отвернулся — гаснет) |
| **Пробел** — смотришь вправо | рычаг двери: закрыть / открыть |
| **ЛКМ держать** розовую кнопку на столе | дэнс пол впереди горит, пока держишь |
| **ЛКМ** по красной кнопке на столе | один звуковой сигнал |
| **ЛКМ** по рычагу справа от правого проёма | закрыть / открыть дверь |
| **F6 / F7 / F8** | заглушить генератор / −20 HP / слить 10 бензина (отладка, пока нет фурри) |
| **F4** | свет: обычный ↔ неон (отладка; в меню — «Настройки» → «Свет») |

В офисе камера встаёт в три положения: влево (−90°), вперёд (0°), вправо (+90°). Следующая
команда срабатывает, когда камера почти доехала: поворот около 0.65 с, подход к генератору около
1.2 с.

## Что уже есть

- **Ночи 1–7** (`Nights`, `NightProgress`) — как во FNAF: ночь открывается, когда пройдена предыдущая, 7-я — ещё
  и если на счету не меньше 50 $ (деньги не тратятся). Пройденное запоминается между запусками. С каждой ночью
  сложнее: 1-я — Стрей, Дали и Нова; 2-я и 3-я — ещё Дир; с 4-й — все пятеро; уровни растут, с 3-й ночи монитор
  сбоит чаще (18% в минуту), звонков клиентов больше (с 3–4 до 8–9). Номер ночи во время игры не пишется.
- **Главное меню** (`MainMenu`) — «Играть», «Настройки», «Выход». «Играть» отъезжает влево (вровень с первым рядом ночей),
  справа появляются **открытые** ночи двумя столбцами по три (пройденные светлее, не пройденные тёмные): 1–6 по мере прохождения, 7-я — когда пройдена 6-я (без 50 $ серая, с причиной),
  «Своя ночь» — отдельная кнопка под списком, когда пройдена 7-я: нажал — ночи уходят, она встаёт наверх, под ней уровни
  фурри (`NightSettingsTab`, на прохождение не влияет), «Назад» — обратно к ночам. Сразу выбрана
  самая дальняя открытая; «Играть» ещё раз — начать. «Настройки»: **«Громкость»** (общая, музыка мог-батла, фон ночи,
  генератор, остальные звуки — `VolumeSettingsPanel`, PlayerPrefs `SSDFNC.Volume.*`; отпустил ползунок — звучит
  пример), **«Звуки»** (то же окно, что в паузе) и **«Скилл-чеки»** (`MogTestTab`): выбрать раскладку и пройти её в окне
  мог-батла. «Назад» / Esc — на шаг назад. Числа анимации — константы в начале `MainMenu.cs`.
- **Смена** (`ShiftTimer`) — идёт 6 минут, оставшееся время — в правом нижнем углу монитора камер («5:59»; без
  питания и при перезагрузке монитора его не видно). В углах экрана надписей нет, подписей у кнопок стола, рычага и
  телефона тоже.
  Время вышло — экран **«Ночь N пройдена»** (`NightEndScreen`) с кнопкой «Следующая ночь»: итоги ночи (сколько раз кормил Дира,
  мог-батлы, звонки, деньги) и кнопки «Заново» и «В меню».
- **Загрузочный экран** (`SceneLoader`) — при запуске игры (сцена `Boot`), перед ночью, при «Заново», при
  выходе в меню и после смерти: название, полоска с процентами, крутилка и случайный совет.
- **Пауза** (`PauseMenu`, Esc в офисе) — время и звук стоят, клавиши и клики игры не работают (`GameFlow`).
- **Звуки** (пауза → «Звуки», `SoundSettingsPanel`): у каждого события — фон ночи, генератор (запуск / работа /
  глушение), дверь, удар фурри об закрытую дверь, красная кнопка, телефон, верный ответ, загрузка перед ночью,
  конец ночи и сразу за ним замок (уходим и запираем; «замок 1» / «замок 2»), сбой монитора, «подошёл» для Доли / Стрея / Дали / Новы, рычание Доли, слив бензина, голод Дира —
  свой звук. ◄ ► меняют его на любой файл из `Assets/StreamingAssets/Sounds` (или «нет», или «встроенный» — звук
  из кода), новый звук сразу слышно и сразу играет в ночи; выбор сохраняется. Свои файлы (wav, mp3, ogg) можно
  просто класть в эту папку. Что стоит по умолчанию — таблица `GameSounds.Slots` в `Assets/Scripts/GameSounds.cs`.
- **Поворот камеры** (`CameraLook`) — три направления, плавный доворот без рывка в конце, и
  подход к генератору через проём. В офисе игрок сидит в кресле во все стороны (глаза на 0.85 м, обзор 70°);
  вперёд камера чуть отъезжает назад и смотрит вниз — в кадре стол, монитор и проход к дэнс полу. К генератору
  игрок встаёт (1.6 м). Числа — константы в начале `CameraLook.cs`.
- **Карта клуба** (`MapBuilder`) — модель из Blender: офис-ресепшен с круглым столом, впереди проход к
  дэнс полу, слева генераторная (дверь в неё открыта), справа рольставень в коридор 2, дальше коридоры и
  проход Г. Игрок стоит у кресла за столом. Внутри свет от ламп: потолок закрывает солнце. Текстуры —
  с Poly Haven в 1K (в `.blend` они не вшиты, их качает `Tools/Blender/download_map_textures.bat`). Как
  обновить карту — [docs/MODELS.md](docs/MODELS.md). Без карты офис собирается старым полигоном.
- **Генератор** (`Generator`, `GeneratorModel`, `GeneratorHandle`, `GeneratorPanel`) — в генераторной
  слева, там, где он стоит на карте. Модель из Blender с анимациями:
  - рывки стартера — генератор заводится через 2.6 с;
  - работающий трясётся;
  - пока заливаешь бензин, крышка бака открыта.

  Пользоваться им можно только вблизи (ближе 3 м), то есть подойдя: смотришь влево и жмёшь W.
  Работает и жжёт бензин (150 за смену). На табло состояние, полоски HP и бензина, остаток в канистрах
  и кнопка «Залить». Кончился бензин — глохнет, заводится кликом по ручке стартера на боку. HP на нуле —
  сломан до конца смены. Числа — в `Balance.cs`. Как обновить модель — [docs/MODELS.md](docs/MODELS.md).
- **Фурри** (`SSDFNC.Core`, `NightDirector`) — пятеро, ИИ как во FNAF: уровень 0–20, бросок кубика
  каждые ~5 с, рост уровня за смену, фиксированные маршруты. Дир в кормушке, Стрей к двери или дэнс
  полу, Нова на дэнс пол (мог-батл), Дали к генератору, Доли к
  двери или генератору. У двери, на дэнс полу, в проходе Г и у генератора их видно — модели из Blender, без имён,
  лицом к игроку. Стрей у двери выглядывает из-за угла, Доли у двери не видно, Дали в проходе Г — рука из вентиляции
  генераторной. Дэнс пол играет музыку («Дэнс пол» в «Звуках»), пока горит.
  Нападение — скример: голова фурри бросается на игрока поверх затемнённой игры (звук «Скример»), потом экран гаснет
  и на чёрном — кто и как убил, кнопки «Начать заново» и «В меню». Дир — сразу чёрный экран «СКОНЧАЛСЯ».
  Подробно — [docs/FURRY_AI.md](docs/FURRY_AI.md).
- **Атака Новы (мог-батл)** (`MogBattle`) — по фазам: Появление → группы скилл-чеков → Нова уходит
  или Смерть. Фаза и запас мога на экране не пишутся — только название чека и подсказка. Нова разворачивает игрока к дэнс полу,
  управление отключено, остальные фурри стоят. Четыре вида скилл-чеков:
  - **кружок** — стрелка бежит по кругу, ПРОБЕЛ в зоне (как в DbD);
  - **кнопка** — как в osu!: круг с белой обводкой, кольцо проявляется и сжимается, клик, когда
    сомкнётся с обводкой; после клика вспышка (белая — попал, красная — мимо);
  - **стрелка** — ждёт взмаха: провести мышью в её сторону, пока кольцо не сомкнулось (не туда — не
    считается; не успел — стрелка краснеет, промах);
  - **полоска** — метка едет, может менять скорость и отскакивать от краёв, ПРОБЕЛ в зоне.

  Чеки идут один за другим: следующий виден сразу, как решён предыдущий, и ждёт своего времени.
  Скилл-чеки идут по **раскладкам под музыку** — json-файлам в `Assets/StreamingAssets/MogCharts`.
  Запас мога: с 3, попал — +1 (до 4), промах — −1; на 0 Нова нападает сразу, дожил хотя бы с 1 — выжил.
- **Редактор раскладок** — отдельная программа `Builds/ChartEditor/SSDFNC Chart Editor.exe`
  (`MogChartEditor`, сцена `MogEditor`; в Unity — SSDFNC → Chart Editor → Open in Play Mode). Импорт
  музыки, волна звука, сетка по BPM, чеки ставятся клавишей B в такт. Выбранный чек виден посередине в
  настоящем окне скилл-чеков, и его можно править мышью прямо там: место кнопки, где зона и какой она
  ширины. Справа — точные числа (скорость, зона, время). Проверка раскладки в окне мог-батла, сохранение
  в json папки проекта, его сразу подхватывает игра. Как пользоваться — [docs/MOG_CHARTS.md](docs/MOG_CHARTS.md).
- **Звонки начальства** — туториал, звонят в начале ночи, некоторые — в середине (время случайное). Отвечать не
  надо: ЛКМ — дальше, после последней реплики гудки; можно не брать трубку. Тексты пока заглушки —
  `Assets/StreamingAssets/Calls/Boss/night_1.json`…`night_7.json`, как писать — [docs/CALLS.md](docs/CALLS.md).
  **Звонок по условию** — `CallDirector.Request("условие")`, текст — `Calls/Triggered/условие.json`; сами условия
  (например клик по точке на камере) — потом. В панели F1 — кнопки «Начальство» и «По условию».
- **Звонки клиентов** (`CallDirector`, `Phone`, `CallDialog`, `ScheduleBoard`) — от 3–4 (ночь 1) до 8–9 (ночь 7) за смену.
  Клиенты спрашивают, что и когда будет ночью, кто свободен, хотят заказать фурри или VIP-комнату.
  Отвечать по табличке «Программа на ночь» на стене слева от прохода (без карты — справа над столом), она
  каждую ночь новая. Окно разговора внизу,
  видно, когда смотришь вперёд. За верный ответ 2–10 $, деньги — в меню. Диалоги — json в
  `Assets/StreamingAssets/Calls`, как их писать — [docs/CALLS.md](docs/CALLS.md).
- **Монитор камер** (`CameraMonitor`) — на экране монитора, что стоит на столе справа (без карты — висит
  над столом): название камеры, кто в комнате, внизу кнопки камер. 7 камер: 1 (не работает — «нет сигнала») и комнаты 2–7; в проход Г и вентиляцию (8) не посмотреть.
  На камере 7 — корм Дира и кнопка «ПОКОРМИТЬ». Без питания от генератора гаснет.
  **Сбой монитора:** с шансом 10% в минуту монитор гаснет и 3 с перезагружается (полоска загрузки),
  камеры и кормление в это время не работают. Только если у Дира корма не меньше 40%. Звука пока нет:
  положи `Assets/Audio/MonitorReboot.wav` (или `.ogg`, `.mp3`) и пересобери офис. Числа — в `Balance.cs`.
- **Отпугивающие факторы** (`Deterrent`) — три вида срабатывания: **разово** (нажал — сработал),
  **пока держишь**, **вкл/выкл** (нажал — включил, ещё раз — выключил).
  - **Дэнс пол** (`DanceFloor`) — 120 плиток карты в коридоре впереди (переливаются по одной), розовая
    кнопка на столе (на внутренней стороне, под столешницей) или пробел, работает, пока держишь. Нужен генератор.
  - **Звук** (`SoundSignal`) — красная кнопка на столе, один гудок за нажатие. Работает и без генератора.
  - **Дверь** (`Door`) — рольставень справа (закрыть — шторка опускается), рычаг под столом справа, у правого
    подлокотника (или пробел, когда смотришь вправо), вкл/выкл. Закрытой можно держать не
    дольше 20 с, потом откроется сама и заблокируется на 10 с. Табличка над рычагом показывает
    отсчёт. Без генератора дверь открывается, рычаг не работает.
- **Сборщики сцен** (`TestPlatformBuilder`, `MainMenuBuilder`, `MogEditorBuilder`) — собирают офис,
  меню и редактор раскладок одной командой; `MogEditorBuilder` ещё и собирает редактор отдельной программой.

## Что доработать

- **Скилл-чеки Новы:** четыре вида и редактор раскладок готовы — надо попробовать руками,
  сделать раскладки под настоящую музыку и подобрать окно попадания и длину взмаха
  (`Balance.MogHitWindow`, `MogSwipeDistance`).
- **Баланс ночей 1–7 проверен только ботом** ([docs/BALANCE_REPORT.md](docs/BALANCE_REPORT.md), «Ночи»): средний
  бот выживает от 86% (ночь 1) до 16% (ночь 7). Пройти руками и подкрутить уровни в `Nights.cs`. Смена стала
  6 минут, а бензина за смену по-прежнему 150 — генератор жжёт его быстрее, чем раньше.
- **Звонки начальства:** написать тексты (`Calls/Boss/night_N.json`, сейчас заглушки); решить, какие условия
  вызывают звонки (`CallDirector.Request`).

  Бот в симуляции звонки пока не учитывает. Цифры — в [docs/BALANCE_REPORT.md](docs/BALANCE_REPORT.md),
  ручки — в `Balance.cs` и `Difficulty.cs`.
- **Звонки надо доработать:**
  - 8 диалогов-черновиков: переписать и добавить новые;
  - решить, что будет за ошибку и пропуск (сейчас ничего);
  - решить, на что тратить деньги;
  - подобрать частоту звонков;
  - сделать приложение-редактор диалогов.

  Как устроено — [docs/CALLS.md](docs/CALLS.md).

## Тестовая сцена (вид сверху)

Это старый полигон: он собирается, только если карты клуба нет (`Assets/Models/Map/Map.fbx`). Офис на
карте — см. [docs/MODELS.md](docs/MODELS.md#карта-клуба).

```
                               ● зелёный шар
                               │
                          ForwardPath
                               │
        ▣ генератор ··        ║[ центр 8×8 ]║        ▮ синий цилиндр
 LeftPath ═════════ ◇ ══ проём ║     ▲      ║ проём ══ RightPath ═════════
                               ║   игрок    ║
                      стена x = −3.5      стена x = +3.5
   ◇ — где встаёт камера у генератора (x = −4.65), глаза на высоте 1.6 м
```

Монитор стоит перед игроком справа внизу: виден, когда смотришь вперёд, и пропадает из
виду при повороте влево или вправо. Под ним ряд из шести цветных кнопок.

Подробно про координаты и устройство — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
