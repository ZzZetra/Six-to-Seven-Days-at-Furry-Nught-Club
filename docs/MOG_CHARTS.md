# Раскладки мог-батла (скилл-чеки под музыку)

Атака Новы идёт по **раскладке**: это трек музыки и список скилл-чеков с точным временем каждого.
Раскладки лежат в json-файлах и правятся руками, код трогать не нужно. Потом для них будет
отдельное приложение (план — в конце файла).

## Как идёт атака

1. **Появление** (фаза 1). Нова встаёт на дэнс пол и разворачивает игрока к нему; если он был у
   генератора, возвращает в офис. Управление отключено, остальные фурри, голод Дира и бензин стоят.
   Начинается музыка. Фаза длится до первого скилл-чека раскладки.
2. **Кружок** (фаза 2), **Полоска** (фаза 3), **В стороны** (фаза 4) — группы скилл-чеков из раскладки.
   Пока все три вида работают как полоска: ПРОБЕЛ, когда метка в зелёной зоне.
3. **Нова уходит** или **Смерть** (фаза 5). Длительность — `Balance.MogOutroTime`.

**Запас мога** (под полоской: «Мог: ■■■□ 3 / 4»): батл начинается с 3. Попал — +1, но не выше 4.
Промах — −1. Дошёл до 0 — Нова нападает **сразу**, остальные чеки не играются. Дожил до конца хотя бы
с 1 — Нова уходит. На последней единице счётчик красный. Числа — `Balance.MogStartLives` (3),
`MogMaxLives` (4), `MogLivesPerHit` (1; поставь 4, если попадание должно сразу поднимать до максимума).

Фаза пишется в правом верхнем углу под часами: «Фаза 3/5: Полоска · 2/5».
Номер фазы берётся из типа чека: кружок — 2, полоска — 3, в стороны — 4. Порядок групп задаёт сама
раскладка, но по задумке он такой: кружки → полоски → в стороны.

## Где лежат

```
Assets/StreamingAssets/MogCharts/
  default.json            раскладка по умолчанию, без музыки (5 + 5 + 5, каждые 2 с)
  мой_трек.json           ← свои раскладки класть сюда
  мой_трек.ogg            ← и музыку к ним
  examples/               примеры, игра их не читает
    metronome.json        метроном 120 BPM: каждый «бит» на сильной доле
    metronome.wav
```

- Игра читает только `*.json` прямо в папке `MogCharts`. Подпапки не читаются.
- Каждый батл берёт случайную раскладку, по возможности не ту же, что в прошлый раз.
- Файл с ошибкой пропускается, причина пишется в Console:
  `[SSDFNC] Раскладка … пропущена: …`. Если рабочих нет совсем, берётся встроенная
  (`MogChart.Default()`, такая же, как `default.json`).
- Музыка: `.ogg`, `.wav` или `.mp3`. Путь — от папки `MogCharts`, например `"music": "мой_трек.ogg"`
  или `"music": "examples/metronome.wav"`.

Чтобы попробовать пример с метрономом, скопируй `examples/metronome.json` в `MogCharts`. Музыку
копировать не нужно: путь в файле уже указывает на `examples/`.

## Формат

```json
{
    "name": "Мой трек",
    "music": "мой_трек.ogg",
    "offset": 0,
    "checks": [
        { "type": "circle", "start": 7, "hit": 8, "zone": 0.22, "pos": 0.55 },
        { "type": "bar",    "start": 19, "hit": 20, "zone": 0.18, "pos": 0.7 },
        { "type": "sides",  "start": 31, "hit": 32, "zone": 0.22, "pos": 0.4 }
    ]
}
```

| Поле | Что это | Если не указать |
|------|---------|-----------------|
| `name` | название (в логе) | имя файла |
| `music` | файл музыки рядом с json | `""` — без музыки, время идёт по часам игры |
| `offset` | сдвиг в секундах: если чеки чуть раньше бита, поставь положительное число (0.05 = на 50 мс позже) | 0 |
| `checks` | список скилл-чеков, порядок в файле не важен (сортируются по `start`) | — |
| `type` | `circle` (кружок), `bar` (полоска), `sides` (в стороны) | `bar` |
| `start` | секунда музыки, когда чек появляется и метка стартует от левого края | — |
| `hit` | секунда музыки — **бит**: в этот момент метка ровно в центре зоны | — |
| `zone` | ширина зелёной зоны, доля полоски (0.22 = 22%) | 0.22 |
| `pos` | где центр зоны, от 0 (левый край) до 1 (правый) | 0.6 |

В json нельзя писать комментарии. Дробные числа пишутся через точку.

### Как считается метка

- Метка едет с постоянной скоростью `pos / (hit − start)` полосок в секунду: от левого края в `start`
  до центра зоны в `hit`.
- Чем меньше `hit − start`, тем быстрее метка. 1 с — спокойно, 0.5 с — быстро.
- `pos` меняет и место зоны, и скорость: при `pos` 0.3 метка ползёт медленнее, чем при 0.8.
- Чек засчитывается промахом, если не нажал, пока метка не дошла до правого края
  (`start + (hit − start) / pos`), или уже начался следующий чек. Поэтому следующий `start` лучше
  ставить не раньше, чем через 0.3–0.5 с после `hit` предыдущего.
- Подряд три промаха с начала — смерть уже на третьем чеке. Первые чеки раскладки лучше делать
  полегче: у игрока ещё нет запаса.
- Нова учится: после каждой победы игрока все зоны уже на 10%, но не уже половины
  (`Balance.MogZoneShrinkPerWin`, `Balance.MogMinZoneScale`).

### Проверка

- Test Runner → EditMode → `MogTests` проверяет все json в `MogCharts`, включая `examples/`:
  файл читается, в нём нет ошибок, музыка на месте.
- В Console во время батла: какая раскладка, каждый чек «попал» или «мимо» с его временем.

## Как подогнать под трек руками

1. Открой трек в Audacity (или любом редакторе звука) и найди секунды битов, на которые нужен чек.
   Если известен темп, бит — `60 / BPM` секунд (120 BPM — каждые 0.5 с).
2. На каждый бит — чек: `hit` = секунда бита, `start` = `hit` минус 1 с (или два удара).
3. Первый чек ставь не раньше 2–3 с: до него идёт анимация появления, а музыка уже играет.
4. Между группами (кружки → полоски → в стороны) оставь паузу 1–2 с, игрок увидит
   «Приготовься: Полоска».
5. Запусти ночь, F1 → «Нова → батл». Если все чеки чуть раньше бита, увеличь `offset`.

## План приложения настройки (следующий шаг)

Логика батла (`MogChart`, `MogTimeline`) лежит в `SSDFNC.Core` без сцены, поэтому приложение
возьмёт её как есть, и чек в нём будет вести себя ровно как в игре. Что нужно:

- открыть трек и раскладку (или создать новую);
- волна звука и шкала времени, чеки поверх неё;
- **запись битов:** музыка играет, жмёшь пробел в такт — на каждое нажатие ставится `hit`;
- перетаскивание чеков, правка `type`, `start`, `hit`, `zone`, `pos`, групповой сдвиг;
- `offset` с проверкой на слух (щелчок на каждом `hit` поверх музыки);
- проиграть батл прямо в приложении, замедлить до 0.5×;
- сохранить json в `StreamingAssets/MogCharts`.

Скорее всего это будет окно редактора Unity (меню SSDFNC → Mog Chart Editor): оно сразу видит
музыку и раскладки проекта, отдельную сборку делать не нужно.
