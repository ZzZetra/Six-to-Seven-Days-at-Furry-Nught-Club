# Звонки клиентов

Днём в клуб звонят клиенты: узнать программу на ночь, заказать VIP-комнату или… фурри на ночь.
Отвечать надо по табличке «Программа на ночь» над столом. Верный ответ приносит деньги.

## Как идёт звонок

1. За смену звонят **4–6 раз**, примерно поровну по смене. Первый звонок — не раньше 40 с.
2. Телефон на столе слева **звенит, мигает лампа, дрожит трубка**. Не взял трубку за **15 с** — звонок пропущен.
3. **Клик ЛКМ по телефону** — взять трубку. Снизу появляется окно: кто звонит и что спрашивает.
4. **ЛКМ в любом месте** — появляются варианты ответа: 3 (или «да / нет» для заказов).
5. Ответ — **мышью по кнопке или клавишами 1–3**. Клиент реагирует на то, что ты сказал: правильного
   ответа он не знает, иначе бы не звонил. Сказал «свободен» — «Отлично, приду», сказал «занят» — «Жаль,
   в другой раз», назвал фурри — «Тогда к Нове и приду». Верный ответ — рядом зелёным **+N $**, неверный —
   та же реплика, только без денег. Через 3 с гудки.
6. Клиент ждёт ответа **40 с** после того, как взяли трубку, потом бросает трубку.

Во время звонка можно делать всё: поворачиваться, жать пробел, кнопки на столе, камеры. Ночь не
останавливается. Окно звонка видно **только когда смотришь вперёд**. Отвернулся — окно пропадает и
ответить нельзя, разговор ждёт. Повернулся обратно — окно снова на месте.

Пока идёт атака Новы, звонки на паузе: телефон молчит, окно скрыто, время звонков стоит.

**Для проверки:** F1 → «Вызвать звонок» — телефон звонит сразу, не дожидаясь плана (если он не занят и
не идёт мог-батл). Внизу панели — счёт звонков за ночь.

Когда смотришь вперёд, камера отъезжает на 0.5 м назад и наклоняется на 12° вниз. Так стол целиком в
кадре, а окно звонка оказывается «под столом». Числа — `CameraLook.ForwardPullBack` и `ForwardPitch`.

## Деньги

- За верный ответ — `reward` из диалога (у готовых диалогов от 2 до 8 $). Если `reward` = 0 — случайно
  от `Balance.CallRewardMin` до `CallRewardMax` (2–10 $).
- Деньги копятся между ночами (PlayerPrefs, ключ `SSDFNC.Money`), счётчик — в главном меню справа сверху.
- За ошибку и пропуск пока ничего не отнимается.

## Расписание

Каждую ночь новое. Игра собирает его случайно из `Assets/StreamingAssets/Calls/schedule.json`:

```json
{
    "times": ["22:00", "23:00", "00:00", "01:00", "02:00", "03:00"],
    "rooms": ["VIP-1", "VIP-2"],
    "freeChance": 0.35,
    "roomChance": 0.2,
    "furries": [
        { "name": "Нова", "female": true, "gen": "Новы", "dat": "Нове", "acc": "Нову", "ins": "Новой",
          "activities": ["DJ-сет", "мог-батл"] }
    ]
}
```

| Поле | Что это |
|---|---|
| `times` | строки таблицы |
| `rooms` | VIP-комнаты: в один час одну комнату занимает не больше одного фурри |
| `freeChance` | доля свободных клеток (0.35 — примерно треть) |
| `roomChance` | из занятых клеток — доля VIP |
| `name`, `female` | имя и пол фурри: от пола зависит «свободен / свободна» и формы в тексте |
| `gen`, `dat`, `acc`, `ins` | падежи имени: у кого (Новы), к кому (Нове), кого (Нову), с кем (Новой). Пусто — имя не склоняется (Дали, Доли) |
| `activities` | чем фурри бывает занят. Пиши с маленькой буквы, как в середине фразы («бар», «шоу на сцене»): в таблице первая буква станет заглавной |

Правила, которые игра соблюдает всегда:
- в каждый час хотя бы один фурри свободен и хотя бы один занят;
- у каждого фурри есть и дела, и свободный час.

Пол Стрея в расписании — «он». Если это не так, поменяй `female` в `schedule.json`.

## Диалоги

Один диалог — один файл в `Assets/StreamingAssets/Calls/Dialogues/`. Каждый звонок игра берёт случайный
диалог и сама выбирает, о чём спросить (время, фурри), по свежему расписанию.

```json
{
    "id": "order_furry_private",
    "type": "OrderFurry",
    "caller": "Таинственный незнакомец",
    "client": "Кхм-кхм… Хочу заказать {furry_acc} на {time}. На… частную встречу.",
    "answer": "",
    "yes": "Да, {furry} в {time} {свободен|свободна}, записываю.",
    "no": "Извините, в {time} {furry} {занят|занята}.",
    "thanks": "Отлично. Буду ровно в {time}. Кхм.",
    "thanksNo": "Жаль… Что ж, в другой раз. Кхм.",
    "reward": 8
}
```

| Поле | Что это |
|---|---|
| `id` | имя диалога, не повторяется |
| `type` | тип вопроса, см. таблицу ниже |
| `caller` | кто звонит — пишется над репликой |
| `client` | что говорит клиент |
| `answer` | как звучит вариант ответа — для типов с выбором из трёх. Игра подставит в него верные и неверные значения |
| `yes`, `no` | варианты «да» и «нет» — для `OrderFurry` и `VipFree` |
| `thanks` | реакция клиента на ответ (на любой: клиент не знает, верный ли он). Для `OrderFurry` и `VipFree` — реакция на «да» |
| `thanksNo` | только `OrderFurry` и `VipFree`: реакция на «нет» — «Жаль, тогда в другой раз» |
| `reward` | $ за верный ответ; 0 — случайно 2–10 |

### Типы вопросов и переменные

| `type` | Клиент спрашивает | Верный ответ | Переменные |
|---|---|---|---|
| `WhatAtTime` | что будет в `{time}` | дело и кто его ведёт | `{time}` `{activity}` `{furry…}` |
| `WhenFurry` | во сколько у `{furry_gen}` `{activity}` | время | `{time}` `{activity}` `{furry…}` |
| `FurryAtTime` | что будет делать `{furry}` в `{time}` | дело или «свободен» | `{time}` `{activity}` `{furry…}` |
| `WhoFree` | кто свободен в `{time}` | свободный фурри | `{time}` `{furry…}` |
| `OrderFurry` | можно `{furry_acc}` на `{time}` | «да», если свободен | `{time}` `{furry…}` |
| `VipFree` | `{room}` свободна в `{time}` | «да», если никто не занял | `{time}` `{room}` |

`{furry…}` — это `{furry}` (Нова), `{furry_gen}` (Новы), `{furry_dat}` (Нове), `{furry_acc}` (Нову),
`{furry_ins}` (Новой).

**Род:** `{свободен|свободна}` — первое слово для него, второе для неё. В начале фразы пиши с большой
буквы: `{Занят|Занята}?`. Можно с любыми словами:
`{пришёл|пришла}`, `{занят|занята}`. Работает везде, где в звонке есть фурри (не в `VipFree`).

**В `answer` обязательно должна быть переменная с ответом**, иначе все три варианта выйдут одинаковыми:
`{activity}` для `WhatAtTime` и `FurryAtTime`, `{time}` для `WhenFurry`, `{furry…}` для `WhoFree`.

Где какая переменная берётся:
- в `client`, `yes`, `no`, `thanksNo` — из вопроса (о ком и о каком часе спрашивают);
- в `answer` — у каждого варианта свои;
- в `thanks` — из того варианта, который выбрал игрок: ответил «свободен Доли» — клиент скажет
  «Тогда к Доли и приду», даже если это неверно. Для `OrderFurry` и `VipFree` — из вопроса.

Не пиши в `client` переменную, которая и есть ответ: «Что будет в {time}? Наверное, {activity}?»
подскажет игроку ответ.

### Неверные варианты

Игра берёт их из того же расписания: другое время, другой фурри, другое дело. Они правдоподобные, но
каждый точно не совпадает с расписанием, и варианты не повторяются. Тесты проверяют это на сотнях
случайных расписаний.

### Как добавить диалог

1. Скопируй любой файл из `Dialogues`, поменяй `id` и тексты.
2. Запусти тесты: Test Runner → EditMode → `CallTests`. Тест `Json_AllDialoguesAreValidAndBuild`
   найдёт опечатку в переменной, пустое поле, повтор `id`.
3. Если файл с ошибкой всё-таки попадёт в игру, он пропускается, а причина пишется в Console:
   `[SSDFNC] Диалог … пропущен: …`.

## Числа

В `Balance.cs`, раздел «Звонки клиентов»:

| Константа | Значение | Что это |
|---|---|---|
| `CallsPerNightMin`, `Max` | 4, 6 | сколько звонков за смену |
| `CallFirstDelay` | 40 с | первый звонок не раньше |
| `CallLastMargin` | 30 с | последний — не позже, чем за столько до конца |
| `CallRingTime` | 15 с | сколько звенит, прежде чем звонок пропущен |
| `CallPatience` | 40 с | сколько клиент ждёт ответа после того, как взяли трубку |
| `CallReactionTime` | 3 с | реплика клиента после ответа |
| `CallRewardMin`, `Max` | 2, 10 $ | деньги, если в диалоге `reward` = 0 |

Симуляция баланса звонки пока не учитывает: они ничего не отнимают, только отвлекают.

## Устройство

- **Логика без сцены** (`Assets/Scripts/Core/Calls`, гоняют тесты):
  - `Schedule` — расписание и его генерация;
  - `CallTemplate`, `CallTypes`, `CallText` — диалог, типы, переменные, проверка;
  - `CallBuilder` — готовый звонок: вопрос, варианты, верный;
  - `CallPlan` — когда звонят.
- **В сцене:**
  - `CallDirector` — ведёт звонки, деньги;
  - `Phone` — телефон;
  - `CallDialog` — окно внизу;
  - `ScheduleBoard` — табличка;
  - `CallData` — загрузка json;
  - `Wallet` — деньги.
- **Тесты** — `Assets/Tests/EditMode/CallTests.cs`.

## Приложение для диалогов (следующий шаг)

Варианты:
- **окно в Unity** (меню SSDFNC → Редактор звонков) — подстановка та же, что в игре;
- **HTML-страница** — откроет кто угодно без Unity;
- **таблица** (Excel / Google Sheets → CSV).

Что в нём нужно:
- список диалогов, поля реплик;
- кнопки вставки переменных, подсказка, какие можно для выбранного типа;
- подсветка ошибок;
- предпросмотр на случайном расписании («Перебросить»);
- сохранение json.
